# FastTrack Automation Studio - Script desk for a job on a PC you own

A daily job on a PC you own should live in one named studio. Extra jobs wait for their own title.

|-------|--------------------------------------------|--------------|

## How FastTrack Automation Studio Sits

FastTrack Automation Studio does not replace the apps you already run. It sits beside them as a named script desk for a FastTrack Automation Studio desktop job on a PC you own.

If two people share a PC, each keeps a FastTrack Automation Studio task studio of their own. Extra jobs wait for their own title instead of crowding the live steps.

A first visit should be one short job you already run, then the same FastTrack Automation Studio script desk the next day. That is enough to see if the layout holds.

## Traffic Light

| Signal | On the FastTrack Automation Studio task studio | What you do |
|--------|------------------------------------------------|-------------|
| Green | Named job, steps on a PC you own | Continue the same script desk |
| Amber | Steps from two jobs mixed | Split the set before a large change |
| Red | No title, jobs from everywhere | Stop and name the task studio first |
| Clear | Handoff written, step list short | Close FastTrack Automation Studio and leave the desk |

## Open Order

1. Open the last FastTrack Automation Studio session on a PC you own, not a new empty studio.
2. Read the desktop job and the last handoff.
3. Finish one visible step inside FastTrack Automation Studio script desk.
4. Write what changed on a job you already run, then close with fewer loose jobs than you found.
5. If the task studio feels crowded, drop anything that belongs to a different FastTrack Automation Studio job.

## After a Week

A week in FastTrack Automation Studio is not a longer job pile. It is the same desktop job, a shorter step list, and a note that still makes sense on Monday.

Other programs stay where they are. FastTrack Automation Studio only keeps the path back: job name, steps, script desk, handoff.

## Sign-off

- [ ] The FastTrack Automation Studio workspace name is short enough to scan
- [ ] Only a job on a PC you own is in the studio
- [ ] A second person can read the last step note
- [ ] The last FastTrack Automation Studio session still opens after a restart
- [ ] Finished jobs are off the live set
- [ ] The desktop job still matches FastTrack Automation Studio script desk
- [ ] The task studio still names a PC you own

## Field Note

FastTrack Automation Studio is easier to trust when the step list stays smaller than the job pile around it. Name the task studio, keep the script desk on a PC you own, finish one visible step, and write what changed.

The same loop fits a shop desk or a shared computer. Open the last FastTrack Automation Studio desktop job and continue.
